# skills

Personal Claude Code skills and subagents.

- `.claude/skills/mercury-3/`: query Inception Labs' mercury-3 (needs the network proxy to inject the bearer token for `api.inceptionlabs.ai`).
- `.claude/agents/mercury.md`: subagent relaying prompts to mercury-3.
- `.claude/skills/agent-rc-profile/`: create and use `agent-rc` profiles (Claude Code in a detached tmux session, macOS sandbox, Remote Control, TokenEconomizer). Includes the `agent-rc` launcher. 0BSD licensed.
